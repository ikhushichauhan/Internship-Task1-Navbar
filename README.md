#  Interactive Navigation Bar

A stylish and interactive navigation bar created using **HTML**, **CSS**, and **JavaScript**. This project features smooth scroll transitions, hover effects, animated background gradients, and responsive design.

---

##  Features

- Fixed navigation bar
- Animated background gradients
- Scroll-based background & font color changes
- Section highlighting and scroll progress
- Hover effects and smooth transitions
- Responsive for desktop and mobile

---

##  Project Structure

.
├── first.html # Main HTML file
├── first.css # CSS for styling and animations
└── first.js # JavaScript for scroll and interaction logic


---

##  Tech Used

- HTML5  
- CSS3 (Gradients, Transitions)  
- JavaScript (Scroll Events, DOM Manipulation)
